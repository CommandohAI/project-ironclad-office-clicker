# Project IRONCLAD Bible

## Game Name

Office Clicker / Corporate Climb Simulator

## Core Idea

The player starts as a low-level office worker and climbs the corporate ladder by working, earning money, buying promotions, and hiring staff.

## Core Gameplay Loop

- Press WORK to earn money.
- Spend money on promotions.
- Promotions increase money earned per click.
- Hire staff to generate passive income.
- Unlock better ranks and office status.
- Add monetisation through boosts, VIP perks, gamepasses, and developer products.

## Main Currency

Money

## Future Currencies

- Prestige Points
- Corporate Influence
- Premium Boost Tokens

## Main Systems

- Work button
- Money display
- Promotions
- Hiring/autogenerators
- Saving/loading
- Rebirth/prestige
- Gamepasses
- Developer products
- Daily rewards
- Tutorial

## Phase 1 Goal

Create a playable core loop:
- Player joins.
- Player sees money.
- Player clicks WORK.
- Money increases.
- UI updates.
