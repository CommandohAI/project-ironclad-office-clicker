# Project IRONCLAD — Office Clicker

A monetisable Roblox simulator/clicker game.

## Core Loop

1. Player presses WORK.
2. Player earns money.
3. Player buys promotions.
4. Player hires workers.
5. Workers generate passive income.
6. Player unlocks higher corporate ranks.
7. Player returns for progress, rewards, and upgrades.

## Current Mission

MISSION 001 — Core Clicker Loop

Goal:
Create a working money system with a WORK button and basic UI.
